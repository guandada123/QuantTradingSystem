# 盘中快照被永久固化 —— "结构合法"不等于"数值正确"

**日期**：2026-09-03
**发现者**：Quant 数据管线自动化（automation-1781663740184）第 4 跑
**等级**：🔴 数据完整性（影响回测输入正确性）
**状态**：已修复（脚本加 `--refresh` + 3072 行已刷新）

---

## 现象

PHASE 3 质量扫描连续 4 轮全绿（`close<=0:0 high<low:0 vol<=0:0 null_close:0`），
管线判定为 ✅ 正常并 [SILENT]。**实际上近 30 个交易日的 K 线全是错的。**

## 根因

`scripts/fetch_kline_tencent.py` 的 `insert_kline()`：

```python
existing = conn.execute(text("SELECT 1 FROM daily_kline WHERE ts_code=:ts AND trade_date=:td"), ...)
if existing:
    continue          # ← 永不更新
```

管线在**交易时段**运行（历史触发时点 09:46 / 09:52 / 11:14 / 13:13），
腾讯 API 对"今天"这根 K 返回的是**盘中未收盘快照**。
该快照一旦 INSERT，因 `continue` 永远不会被最终日 K 覆盖。

次日再跑时，抓取窗口虽包含昨天，但昨天那行已存在 → 再次 `continue` → 脏数据永久固化。

## 危害量化（备份 vs 权威值，1480 行）

| 指标 | 中位数 | P90 | 最大 |
|---|---|---|---|
| 成交量偏差 | 62.8% | 99.5% | 99.9% |
| 收盘价偏差 | 0.54% | 4.39% | 13.49% |

- 816 行成交量偏差 > 10%
- 极端样本：`SZ002463` 2026-08-19 的 DB 行为 `open=high=low=close=118.07`、
  成交量 6610 手，而真实全天为 522334 手（仅 1.3%，即开盘瞬间快照）
- 受影响区间：2026-07-01 ~ 2026-09-02，共 29 个交易日（08-04 起全池 32/32）

## 为什么三轮校验都没抓到 ★核心教训

**质量扫描只查"结构不可能"，不查"数值不正确"。**

`close<=0` / `high<low` / `vol<=0` 这类判据，只能拦截物理上不可能的值。
盘中快照的 OHLC 完全自洽（open/high/low/close 满足 high>=max(o,c)、low<=min(o,c)），
成交量也只是偏小而非为负 —— **它在结构上是 100% 合法的一根 K 线，只是不是那天的日 K。**

→ **判据设计原则**：区分两类校验，缺一不可。
1. **结构校验**（已有）：字段非空、数值域合法、OHLC 自洽。能拦崩溃级错误。
2. **一致性校验**（本次缺失）：与权威数据源对拍。能拦"合法但错误"。

本次正是靠"拿 DB 与腾讯 API 逐日对拍成交量"才暴露问题——
成交量是最灵敏的探针，因为它在日内单调递增，快照必然系统性偏小；
而价格可能在尾盘回落至接近快照值，单看价格会漏判。

## 修复

1. `insert_kline()` 增加 `refresh: bool` 参数；`--refresh` 时
   已存在行执行 `UPDATE open/high/low/close/vol/amount` 而非 `continue`。
2. 修复前备份 1512 行 → `/tmp/qts_backup/daily_kline_before_refresh_20260903.csv`。
3. 以 `--days 95 --refresh` 全量刷新，32 只 × 96 根 = 3072 行。
4. 复验：成交量偏差 >2% 的日期从 30 个降至 1 个（仅当日，因盘中未收盘，属预期）。

## 遗留

- 当日 K 仍会在盘中写入并固化 → 建议增开 **15:30 盘后重跑（`--refresh`）**，
  或将本管线整体改到盘后。这是唯一能让"当天拿到当天最终日K"的办法。
- `000001.SZ` 两源冲突 / 38 只遗留标的 / `pre_close·change·pct_chg` 长期 NULL —— 三项旧决策未变。

## 可复用的取证手法

想判断某套行情数据是否被"快照固化"，不必逐只肉眼看：

> 取一只标的，同时拉 (a) 数据库最近 12 根 与 (b) 数据源最近 12 根，
> 比对**成交量**比值。若历史日期（非当日）也出现系统性偏小，
> 且比值随日期无规律（1.3% / 19% / 53%…），即可确诊为盘中快照固化。
> 若比值是常数（如恒为 1/100），则应怀疑单位换算问题而非快照问题。
