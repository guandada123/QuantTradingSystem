# execution-service 依赖**约束**文件（pip `-c` 用）—— 2026-10-11 加
#
# 为什么：Dockerfile 原为 `pip install -e ".[execution,shared]"`（**不带版本**），
# 每次重建都会自由解析最新依赖。2026-10-11 strategy-service 就是因此把
# SQLAlchemy 漂到 2.1（其 postgresql:// 默认 DBAPI 变为 psycopg v3，镜像只有
# psycopg2）→ create_engine 抛错被裸 except 吞掉 → **服务静默改用 SQLite**。
#
# 用法：`pip install -e ".[execution,shared]" -c constraints.txt`
#   —— constraints 只**约束版本**，不新增/删除依赖；解析冲突会直接失败（好过静默漂移）。
